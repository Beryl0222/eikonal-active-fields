# 离散到达时间场
所有速度场为合成数据，不表示真实机器人规划或控制。二维直角格点用(row,col)和正步长hy/hx；free/obstacle/missing三种类型。free速度f>0，obstacle无未知量且不通行，missing缺少f不能当作障碍或默认f；其speed字段是未生效占位，不能视作测得速度。每个起点有稳定id、位置及初始时间t0；不同起点可同位置，取最早t0并保留平局来源。模型是标准一阶Godunov离散：每轴选相邻可达时间的较小值a_x/a_y，在未知T上满足sum_axes(max(T-a_axis,0)/h_axis)^2=1/f^2；不存在可达邻居的轴不贡献。起点固定其最早t0，非起点为最早非负因果解。图边界外无邻居，不是额外零起点。
公开数值界为方程残差<=1e-7*(1+1/f^2)，时间atol1e-6/rtol1e-5。missing区域未知速度的公开范围[f_min,f_max]用于给界；若上下界的差<=time_tol且来源一致可确定，否则保持未定。来源为活跃前驱所能追溯的起点集合，平局阈值1e-8*(1+abs(T))，不能按访问顺序裁成唯一来源。起点及场修订会重新定义解，旧版本仍可按其输入解释。
普通梯度只接受局部活跃轴及最小邻居均具有gap>1e-5，且隐式方程对T的导数>1e-7、残差合格并且所依赖速度均已知的范围。其余点标不可微/未定，不用任意子梯度冒充普通导数。上游余量作用于指定T，返回free速度及可训练t0的VJP，固定障碍和位置不求导。间接依赖不可微节点的读出同样没有该普通VJP。损失仅按有资格的读出权重归一，全拒绝不更新。对不跨gap的差分rtol5e-4。
资料有小全场，以及较大field-profile（256×256、32×32块、8起点）可由make_capacity.py按固定seed生成输入；正式支持512×512。允许外部存储时间/依赖资料，内存最多8个块加8MiB辅助数据；所有重新访问计入请求block_reads（典型最多5000）。不能物化全格点雅可比。查询窗口只限制输出，不把其边界当传播边界。编辑后返回版本及未完成范围，不可用旧版本冒充当前。

补测请求由pending_requests列出，包含用途prediction/training、矩形、非负权重和time_horizon。缺测块有稳定block_id、revision及费用，实测记录必须说明采集单号与块身份；在途块不重复下单或收费。计划候选只包含尚未下单的缺测块，总费用不超过budget。名义分析将候选块的missing速度替换为公开区间中点，其余missing保持速度界，不能写入正式速度场。规划收益为每个请求加权的平均时间界宽度下降，加其training_weight乘新增普通梯度合格读出比例；界宽超过time_horizon或无穷时按horizon计，范围在[0,horizon]。共享请求/块只按此全组收益计一次，不能把各块单独收益相加。选收益最大的合法候选集，平局选费用少者，再按block_id排序字典序。名义字段与已测字段分开返回。未发计划遇编辑要重判，已发单号不删除，收到实测后才影响正式预测和训练资格。
